Non-Financial Ways to Support

Code, testing, documentation, and feedback are equally vital to the durability of open-source software.

  • ⭐
    Star the Repository on GitHub
    Helps increase visibility for offline-first tooling in the Android and developer ecosystem.
    Star qixev-fieldkit ↗
  • 🐛
    Report Bugs & Regressions
    Encountered an unexpected edge case or device failure? Submit an issue with reproducible logcat.
    Open an Issue on GitHub ↗

    Recommend FieldKit to independent repair professionals, makers, and mechanics who value local-only data privacy.
