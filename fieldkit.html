Qixev FieldKit

A zero-bullshit, offline-first workshop inventory and work-unit tracking system built for demanding physical workshops and field operations.

View Source on GitHub ↗ Release History

Core Architectural Guarantees

Zero Network Surface

The application manifest contains no android.permission.INTERNET. The operating system physically guarantees that no background requests or network leaks can occur.

Local SQLite Database

All inventory items, job tickets, allocations, and customer records reside in an embedded Room database stored securely on the local device filesystem.

Discrete Inventory Allocations

Parts allocated to a work unit record quantity, timestamp, operational location (bench/rack), and purpose. Multiple allocations of the same item are preserved as distinct, traceable events.

Atomic Stock Restitution

Deleting an allocation record safely returns only its allocated units to stock. Cancelling a work unit executes a single transactional restitution of all allocated items back to inventory.

System Specifications

  • Platform: Native Android (Jetpack Compose + Material 3)
  • Runtime Requirement: Android 8.0 (API 26) through Android 16 (API 37)
  • Application Footprint: Approximately 2 MB (R8 minified release build)
  • License: GNU General Public License v3.0 or later (copyleft)
  • Telemetry / Analytics: None
  • External Accounts / Cloud Sync: None

Open Source & Verifiability

FieldKit is completely free and open-source software. You can clone the repository, inspect every line of Kotlin code, compile reproducible debug or unsigned release builds, and verify its offline guarantees yourself: 

git clone https://github.com/Akshanshk19/qixev-fieldkit.git
cd qixev-fieldkit
./gradlew assembleRelease

Release builds are intentionally decoupled from private signing keys. Contributors and open-source distributors (such as F-Droid) can compile clean release APKs without access to internal signing credentials.
