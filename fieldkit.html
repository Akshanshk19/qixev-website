Software Product

Qixev FieldKit

An offline-first Android application developed by Qixev for independent repair technicians, maintenance engineers, mechanics, and workshop managers. Built for demanding physical environments where network connectivity is unavailable or undesirable.

Download Release APK ↗ Inspect Source on GitHub ↗

Product Overview

Target Audience

Independent repair professionals, field mechanics, electronic technicians, and physical workshop operators who require fast, private, and dependable parts and job tracking on the floor.

Zero Network Surface

The application manifest contains no android.permission.INTERNET. The operating system physically guarantees that no background requests, tracking, or network leaks can occur.

Local SQLite Database

All inventory items, job tickets, allocations, and customer records reside in an embedded Room database stored securely on the local device filesystem.

Discrete Allocations & Restitution

Parts allocated to a work unit record quantity, timestamp, bench location, and purpose. Cancelling or editing work units transactionally returns allocated units back to active inventory.
